# ShopEase – E-Commerce Website

## 1. About the Project
ShopEase is a front-end e-commerce website that provides a simple online shopping experience. Users can browse products, search by name, filter by category, manage a shopping cart, and get budget-based product suggestions.

## 2. Objectives
- Create a user-friendly shopping website.
- Make product searching and browsing easier.
- Implement shopping cart and price calculations.
- Practice HTML, CSS, and JavaScript.

## 3. Features
- **Product Display:** View products with images and prices.
- **Search:** Find products by name.
- **Category Filter:** Browse products by category.
- **Shopping Cart:** Add, remove, and update product quantities.
- **Order Summary:** Calculate subtotal, delivery charges, and total.
- **Smart Suggestions:** Find products based on category and budget.
- **Responsive Design:** Adapt the layout to different screen sizes.

## 4. Technologies Used
- **HTML5:** Website structure.
- **CSS3:** Styling and responsive layout.
- **JavaScript:** Search, filtering, cart, and recommendations.
- **Git & GitHub:** Version control and project hosting.

## 5. Project Structure
- `index.html` — Main website page.
- `style.css` — Website styling.
- `script.js` — Product data and interactive functions.
- `README.md` — Project documentation.
- `ShopEase_Task_Output.pdf` — Project output screenshots.

## 6. How to Run
1. Download or clone the repository.
2. Open the project folder.
3. Open `index.html` in a browser.
4. Alternatively, use VS Code Live Server.
5. Test the available website features.

## 7. Testing
Test product display, search, category filtering, cart operations, order calculations, and budget-based suggestions. Record results after checking each feature.

## 8. Limitations
- Product data is predefined.
- No connected database or backend.
- No real user authentication or payments.
- Smart Suggestions uses rule-based filtering, not real AI.
- Real order processing and tracking are unavailable.

## 9. Future Improvements
- Add user registration and login.
- Integrate a database and backend.
- Implement secure online payments.
- Improve product recommendations.
- Add order tracking and customer support.

## 10. Project Output
Screenshots of the website are available in `ShopEase_Task_Output.pdf`.

## 12. Conclusion
ShopEase demonstrates the use of HTML, CSS, and JavaScript to build an interactive shopping website. It provides practical experience in front-end development and can be extended with a backend, database, and payment system.
